# Why there is no editing front end

A researcher asks for coverage, records an interview with evidence, reviews themes and assigns an action. The CLI applies those changes to a database. Claude Code, Codex, OpenCode or Cursor can run the documented commands.

A screen gives people forms, mobile access and shared navigation. This base supplies none of those and has no offline synchronisation, call recording, meeting scheduler or live dashboard. The HTML files are private read-only snapshots. They are regenerated after a change and never accept input.

Use npm run view for the week, themes and record checks. Use npm run docs for interview briefs and action reviews. brand.json controls the business name, logo and colours. Enterprise DNA can build a team screen and connections into your version.

Interview skill is still work. A database does not replace an independent interviewer, verify a person's words or remove selection bias. The base makes the evidence and follow-up inspectable.
